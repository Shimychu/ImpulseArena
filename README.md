# Impulse Arena

Impulse Arena is a small multiplayer physics arena game built in Unreal Engine 5 with C++.

The goal is simple: use abilities to knock the ball into the opposing team's goal.

This project is mainly a gameplay systems showcase focused on:

* Gameplay Ability System (GAS)
* Chaos Physics
* MassEntity
* Multiplayer networking
* C++

## Planned Gameplay

Players will have abilities such as:

* Force Push
* Double jump
* Dash
* Shield
* Sprint

Abilities can affect the ball, other players, and parts of the environment.

The arena will also include destructible objects using Chaos Physics and a lightweight spectator crowd using MassEntity that reacts to goals and other gameplay events.
